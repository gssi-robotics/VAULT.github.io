Reactive Safe Navigation

VAULT: Vision-Aware Unified Layer for safe Traversal

A two-layer runtime safety framework that combines a learned navigation policy (NoMaD) with a reactive look-ahead obstacle avoider (VFH*) on top of monocular metric depth (Depth-Anything-V2) in a polar coordinate system.

View on GitHub
Abstract

End-to-end learned navigation policies achieve strong goal-directed behavior from raw visual observations, but they do not provide explicit runtime checks on the safety of proposed actions. Our answer is that a robot should rely on learning for nominal goal-directed behavior and invoke reasoning when a proposed action may violate local safety constraints. We present VAULT, a vision-based runtime safety framework that uses monocular depth to verify actions proposed by a learned navigation policy and to override them only when local safety constraints are violated. We instantiate VAULT by combining NoMaD, Depth Anything V2, and VFH* so that learned goal-directed behavior is preserved when safe and replaced with a safer direction when necessary. We implement the framework on a TurtleBot4 under ROS2 Humble and validate it against some challenging scenarios. Experiments in unseen environments show that VAULT improves runtime safety over learned-only and reactive-only baselines while retaining configurable, goal-directed navigation.

Architecture

Two-layer pipeline

The system runs in a continuous loop: Depth-Anything-V2 estimates per-frame metric depth from the OAK-D camera, VFH* builds a polar obstacle histogram and selects a safe heading bin, while NoMaD generates a trajectory that is then projected onto the chosen bin for the final velocity command.

🗺 Exploration mode

Pure NoMaD + VFH* loop — the robot explores autonomously without a predefined goal. NoMaD samples subgoal waypoints while VFH* continuously guards against obstacles.

./run_exploration.sh

🎯 Goal-oriented mode

Adds YOLOv8 on top of the exploration stack. Once the target class is detected the navigator locks onto it and manoeuvres around dynamic obstacles to reach it.

./run_navigation.sh

Quick Start

The full deployment code is open-source on GitHub. Requires ROS 2 Humble, a CUDA-capable GPU, and a TurtleBot 4 with the OAK-D camera. The Model is able to be adopted to any robot with corresponding camera intrinstics.

# 1. Clone the repo
git clone https://github.com/MahsaNikmard/VAULT.github.io VAULT
cd VAULT

# 2. Clone Depth-Anything-V2 alongside
git clone https://github.com/DepthAnything/Depth-Anything-V2.git

# 3. Create conda env
conda create -n VAULT python=3.10
conda activate VAULT
pip install torch torchvision diffusers efficientnet-pytorch \
            ultralytics opencv-python pyyaml matplotlib pillow

# 4. Fix config paths
grep -rl "<USER>" deployment/config | xargs sed -i "s|<USER>|$USER|g"

# 5. Run exploration
./run_exploration.sh

# 6. Run goal-oriented navigation
./run_navigation.sh
